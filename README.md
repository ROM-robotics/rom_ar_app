### ROM AR APP

Android app ကို **Kotlin** နဲ့ ရေးထားတာပါ။ Native Android project ဖြစ်ပြီး Gradle (Kotlin DSL) သုံးထားပါတယ်။

Kotlin files ၃ ခုရှိပါတယ်:
- ConnectionActivity.kt
- MainActivity.kt
- WebAppInterface.kt

UI ပိုင်းမှာတော့ **WebView** ကို သုံးပြီး HTML/JavaScript web app ကို load လုပ်ထားတဲ့ hybrid approach ဖြစ်ပါတယ် (`assets/web_app/` folder ထဲမှာ JS files တွေပါပါတယ်)။
